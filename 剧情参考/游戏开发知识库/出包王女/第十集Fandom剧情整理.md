# 第十集剧情整理：斯黛拉的宇宙偶像企划与“逃税石化”终场

## 结论先行

用户指出的角色是 **斯黛拉（ステラ）**。官方口径能确认她同时是菈菈的“粉丝团兼友之会兼后援会”会长，以及一家 **艺能事务所／演艺公司的社长**；现有官方页面不能证明她是菈菈已经签约的私人经纪人。

本集最强的笑点也确实不只是“她逃税”，而是一条连续反转：

> 斯黛拉嫌公开试镜花钱 → 马上幻想靠菈菈等人赚大钱、买豪宅 → 职员来电说公司逃税已被宇宙税务机构查出 → 她因震惊第二次石化 → 石化状态下被返航装置送走并撞穿屋顶 → 原作梨斗只剩一句“屋顶怎么办”。

准确措辞应是“逃税被查出／暴露”。本集没有演到税务人员现身、逮捕、审判或定罪。

## 斯黛拉的身份口径

能安全采用的写法是：

- 菈菈的粉丝团会长；
- 同时兼任友之会与后援会会长；
- 自己经营一家艺能事务所／演艺公司，是公司社长；
- 想让菈菈重返宇宙并作为偶像歌手推出唱片；
- 得知巨大冲击时会像石头一样僵住，这是本集前后两次使用的种族笑点。

不能直接采用的写法是：

- “菈菈的私人经纪人”或“菈菈已经签约的经纪公司老板”；
- 社区字幕标题卡中的英文公司名或 `Stella Dumpty` 姓氏；
- 未经画面核对的粉丝团精确人数；
- “最后被税务局抓走”。来电者是公司侧未具名职员，税务机构只通过报告存在，返航装置也由职员一侧启动。

## 按时间顺序整理的剧情

### 1. 春菜梦境是假甜蜜，醒来立刻变成菈菈式晨间骚动

原作梨斗在梦中遇见春菜，场面朝着亲密告白或接吻发展；正要如愿时，他从梦里醒来，发现身边的实际状况又被菈菈打乱，随后因刺激过度昏倒或失去反应。

不同社区摘要对枕头、姿势和穿着的描述不完全一致。当前只冻结“春菜梦境假开场—醒来看到菈菈在近处—梦境破灭—晨间昏倒”的节奏，不补写未核实的身体细节。正式改编时，梦境中的欲望和是否主动接吻不能强加给 User。

### 2. 原作梨斗在公园喘息，发现萨斯丁正带陌生外星女性去结城家

原作梨斗为连续发生的晨间骚动感到疲惫，独自在公园或户外整理情绪。他偶然看见萨斯丁护送一名陌生女性朝结城家方向前进，于是跟了回去。

这段只负责把主角带回事件现场。萨斯丁的职能是引路和护送，不是斯黛拉的雇员，也不是税务事件的知情者。

### 3. 斯黛拉登门，报出“三重会长”身份

菈菈认出访客是斯黛拉，并把她介绍为自己的粉丝团会长。斯黛拉随后把头衔补全：粉丝团、友之会、后援会都由她担任会长。

社区材料还写到她曾经就是最危险、最狂热的一名粉丝，后来为了管理其他过激粉丝而被推上会长位置。这能解释她为什么既崇拜菈菈，又会用强硬方式安排菈菈的人生；但精确人数和闪回动作仍待画面核对。

### 4. 偶像唱片企划遭拒，斯黛拉第一次石化

斯黛拉此行的真正目的是把菈菈带回宇宙，包装成偶像歌手并推出唱片。菈菈拒绝，因为她想留在地球，而且已经把原作梨斗称作自己的未婚夫。

斯黛拉完全没预料到这件事，受到巨大打击后当场像石像一样僵住。台词随即解释：她的种族遭遇剧烈惊吓时会石化。这个桥段不是一次性怪癖，而是终场逃税电话的必要规则铺垫。

正式改编时，菈菈说出的未婚夫位置可映射给 User；这只保留菈菈的公开主张，不替 User 自动确认恋爱、婚约或好感结算。

### 5. 恢复后迁怒原作梨斗，逼他找“代替菈菈的金蛋”

斯黛拉僵了很久才恢复。她把菈菈无法出道的原因归到原作梨斗身上，激烈追问甚至用自身能力勒住或攻击他；菈菈回来后制止冲突。

斯黛拉接着提出交易式要求：既然菈菈不能出道，梨斗就必须负责找出足以替代她的新人，也就是能被包装成宇宙明星的“金蛋”。正式改编中，这个被强迫承担寻找任务的位置属于 User，但 User 对威胁的感受和回应不预写。

### 6. 街头物色失败，斯黛拉凭“闻出金蛋”的直觉锁定春菜

斯黛拉带着原作梨斗到街上找人，对若干路人候选都不满意。她随后声称嗅到或感知到真正“金蛋”的气息，一路追到西连寺春菜家附近，并认定春菜具有成为大明星的资质。

这里的“嗅觉”是夸张星探能力，不应在正式世界书中无条件扩展成能识别一切人物潜力的全知异能。

### 7. 斯黛拉反复抢人，原作梨斗反复保护春菜，误会越滚越大

斯黛拉试图直接把春菜带去做艺人；原作梨斗为了阻止她强行拉走春菜，多次挡在中间。由于动作发生得又快又近，春菜看到的往往只是梨斗突然冲向自己或作出尴尬姿势，因而不断误会他的意图。

这段的核心不是春菜已经同意签约，而是“星探强抢—主角拦截—主角反被误会”的重复升级。具体抓取方式、每次误会的构图和次数尚未逐帧核对，不能靠摘要补齐。

### 8. 回到结城家讨论新人，公开试镜因“要花钱”被斯黛拉否决

寻找春菜失败或受阻后，众人回到结城家继续讨论。有人提出举行公开试镜，从大量候选中寻找新人；斯黛拉却直接拒绝，理由不是时间不够，而是她不愿意为试镜花钱。她随即被吐槽过分吝啬。

这个看似小的对话必须留下，因为结尾的税务反转正是对她“既想赚宇宙级大钱、又舍不得付正常成本”的商业人格进行回收。

### 9. 美柑、菈菈与原作梨斗被凑成三人喜剧组合

美柑对艺人企划表现出兴趣，斯黛拉又看见菈菈、原作梨斗与美柑之间天然的吵闹节奏，于是临时把三人当成能做漫才或综艺表演的组合。菈菈兴致很高，原作梨斗则在配合、反驳或纸扇吐槽中成为挨打的一方。

本段可以保留家庭喜剧和漫才节奏，但美柑仍是未成年人；不能借“艺人包装”将她成人化、性化，也不能替她建立长期演艺合同。纸扇由谁在第几拍挥下，仍须看片确认。

### 10. 斯黛拉已经开始做发财梦

看到组合似乎有效果，斯黛拉立刻幻想把他们推成银河或宇宙顶尖艺人，并进一步想到高级办公地点、用途可疑的别墅和源源不断的财富。

这段紧跟在她嫌试镜花钱之后，暴露出她并不是没有商业欲望，而是只想少付成本、多拿收益。它与下一通电话之间几乎没有缓冲，笑点因此具有“刚夸口就被现实打脸”的速度。

### 11. 职员来电：公司逃税已经被宇宙税务机构查出

一名未具名的公司职员紧急联系斯黛拉，报告宇宙税务机构已经发现或查出了公司的逃税问题。

这就是用户特别指出的核心反转。需要保持三个边界：

1. 被查出的是斯黛拉经营公司的逃税，不是菈菈粉丝团本身被定罪；
2. 电话只报告“查出／暴露”，不能升级成斯黛拉已经被捕或法院定罪；
3. 来电者没有可靠姓名，不能因为 Fandom 角色表列出其他职员，就把其中某人硬塞进这通电话。

### 12. 第二次石化、强制返航、撞穿屋顶与死鱼眼收尾

斯黛拉听见逃税曝光后再次遭受巨大冲击，立刻以和前半集相同的方式石化。未具名职员要求她马上返回宇宙，并从远端或通讯端启动返航装置。石化的斯黛拉来不及辩解，直接被送上天，还撞破了结城家的屋顶。

菈菈在她离开后仍兴冲冲地提议大家组成巡回宇宙艺人团；原作梨斗却只关心眼前最现实的问题：被撞坏的屋顶怎么办。宏大的宇宙明星梦、公司的税务丑闻和一个要修的屋顶被压进同一个结尾，形成最后一层落差。

正式改编时，屋顶余波的现场位置归 User，但不需要逐字强迫 User 说原作台词；只要保留“别人还在畅想，主角注意到现实损失”的语义职能即可。

## 主要因果链

1. 原作梨斗从春菜梦境中醒来，又被菈菈制造的晨间状况击倒；户外喘息时发现萨斯丁带斯黛拉去结城家。
2. 斯黛拉以菈菈三大粉丝组织会长和艺能事务所社长身份登场，提出偶像唱片企划。
3. 菈菈以留在地球和已有未婚夫为由拒绝；斯黛拉第一次石化，从而建立“剧烈惊吓会石化”的规则。
4. 斯黛拉把责任推给原作梨斗，逼他寻找代替菈菈的“金蛋”。
5. 她在街头搜索后盯上春菜；原作梨斗反复阻止强行带走，反而不断遭春菜误会。
6. 公开试镜方案被斯黛拉以“花钱”为由否决；随后美柑、菈菈与原作梨斗的家庭吵闹被她包装成三人艺人组合。
7. 她刚开始幻想宇宙级名气、豪华办公地和财富，职员就报告公司逃税已被宇宙税务机构查出。
8. 斯黛拉第二次石化，职员启动返航装置，把她送走并撞穿屋顶；菈菈继续畅想，原作梨斗以屋顶维修问题收尾。

## 为什么“逃税被发现”是全集最强笑点

### 1. 前面早埋了商业人格，不是结尾随机丢一句

斯黛拉并非突然因为“逃税”这个词而好笑。她先拒绝需要花钱的公开试镜，显示极端抠门；很快又幻想豪宅和无穷收益，显示贪心。税务电话刚好把这两点合并成讽刺性的答案：她不是不会花钱，而是连该付的成本与税都想省。

### 2. 第一次石化是规则，第二次石化才是回收

菈菈宣布自己有未婚夫时，斯黛拉第一次石化，观众已经知道她遇到巨大打击会僵住。结尾没有另发明一种反应，而是用“逃税曝光”触发完全相同的生理规则。第一次是人物怪癖，第二次变成回调；后者因原因更世俗、更丢脸而更强。

### 3. 语言反转马上升级为物理破坏

电话并没有停在口头揭丑。斯黛拉还处于石化状态，就被公司侧直接启动返航装置，像一件无法申辩的行李一样发射出去，并撞穿结城家屋顶。商业讽刺、种族反应和物理喜剧在几秒内叠加。

### 4. 屋顶吐槽让笑点落回日常损失

菈菈仍想着全班去宇宙巡演，原作梨斗却面对一个真实的破洞。最后一句不再解释税法，也不追问斯黛拉会不会受罚，只把宇宙级闹剧落在“谁修屋顶”上。这个死鱼眼式余波让整条笑点闭环。

因此后续改编不能只写“最后斯黛拉因逃税离开”。最小完整链必须是：

`吝啬试镜 → 炫富幻想 → 逃税查出 → 石化回收 → 火箭穿屋顶 → 屋顶吐槽`

## 角色职能与改编映射

- 原作结城梨斗：正式改编中由 User 承接梦醒、跟随斯黛拉、被迫找新人、阻止春菜被强拉、参与三人漫才及关注屋顶的剧情位置。不能让男性梨斗作为另一名现实人物并存。
- 菈菈：认出斯黛拉、拒绝偶像企划、说明斯黛拉种族石化规则、制止迁怒、参与三人组合并在结尾继续畅想。她的拒绝和行动权不能交给 User 代办。
- 斯黛拉：粉丝组织三重会长、艺能事务所社长、强势星探与税务反转的中心。必须保留两次石化的对应关系和公司逃税责任，不能洗成无辜旁观者。
- 春菜：被斯黛拉认定为“金蛋”的目标，也是阻拦动作产生误会的接收者。她没有因此同意出道、签约或建立与 User 的固定恋爱结论。
- 美柑：对企划感兴趣并参与家庭式三人漫才。保留聪明吐槽与家庭感，不成人化、不性化、不结算演艺事业。
- 萨斯丁：只负责把斯黛拉带到结城家；不接管公司、税务或返航操作。
- 未具名职员与宇宙税务机构：前者报告并启动返航装置，后者查出逃税；两者不能合并成一名现场执法角色。
- 夕崎梨子：原动画本集没有对应职能。若正式适配时出现，只能按项目最新权威作为 User 的青梅与美柑的姐姐保留有限日常位置，不能抢走原作梨斗、春菜或美柑的节拍。
