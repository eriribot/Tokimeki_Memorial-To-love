# 第十二集剧情整理：猿山实况下的战栗体育祭与沙姬路线种子

## 结论先行

第十二集是彩南高中的体育祭回，原版主轴不是严肃竞技，而是由 **猿山贯穿全场的过度热血实况**，把越来越离谱的项目包装成正规赛事：沙姬在运动员宣誓时公开向菈菈挑战，借物赛把参赛者一个个赶出场，恋爱主题障碍赛把人生难题做成赛道，连寻找“传说之剑”又把接力赛劈出地裂，最后沙姬甚至用天条院集团技术把操场改造成泳池，强行与菈菈进行水上骑马战。

本企划从这一集开始把 **天条院沙姬确立为独立可攻略候选**。这不是说她在原版第十二集突然爱上主角，也不代表当前运行时已经解锁她。最适合本集的路线种子，是让她从第五集“单方面拿 User 刺激菈菈”，发展到这次必须正面询问 User：

> 沙姬提出把“赛后优先邀请 User 一次”列为胜负的附加赌注 → 菈菈只能表示愿意参加，不能替 User 答应 → User 可以拒绝、同意或限缩条件 → 沙姬把普通骑马战升级成泳池科技战后，必须再次确认 User 是否仍同意 → 即使菈菈按原版赢下比赛，她也只获得一次发出邀请的优先机会，User 仍可接受或拒绝。

本集也不能因为时代与内容边界改变，就把所有身体喜剧删成干巴巴的运动会报告。应保留 **只以 User 为接收视角的轻度、非露骨“福利”**，而且 User 自己也可以稍微卖肉：水花把 User 淋湿、安全内层之外的运动外套／号码布被装置划坏、止跌时发生短促近距离接触、有人递毛巾或靠近确认伤势。女主角若有外层装备滑脱、遮挡或贴近反应，也只能发生在 User 的即时近距视角，并立刻恢复遮挡，不能转播给全校。所有学生角色均按未成年人边界处理：安全内层和遮挡始终完整，不描写裸体、内衣或性化身体部位；普通学生、路人男生、校长、猿山和全校观众都不能成为女学生身体喜剧的“福利接收者”。

因此，正式改编需要同时保住三件事：

1. 沙姬与菈菈真刀真枪的竞争，以及菈菈按原版取胜；
2. 沙姬开始尊重 User 的选择权，由此获得路线发展的入口；
3. 猿山完整的赛事解说和玩家定向轻度身体喜剧都存在，但公共卖肉、集体脱衣和校长凝视被改写掉。

## 按时间顺序整理的剧情

### 1. 原作梨斗想借体育祭向春菜表现，幻想先赢在现实前面

体育祭当天，原作梨斗显得格外兴奋。他把好天气放在其次，真正期待的是自己若在比赛中表现出色，也许能得到春菜的注意。短暂幻想里，春菜为他加油，他则完成漂亮成绩。

这段是开场人物动机，但不能在正式改编中直接写成 User 已经选择春菜路线、必然想取悦她或预设告白结果。可以把“今天是公开表现自己的机会”留给 User，再由玩家决定是想回应春菜、关注菈菈、注意沙姬，还是单纯认真参赛。

### 2. 猿山担任总解说，沙姬把运动员宣誓变成对菈菈的挑战书

猿山以异常正式、热血的口吻宣布选手入场，主动报出自己是当天解说。他把普通高中体育祭说成赌上青春、汗水与荣耀的决战，也由此成为整集的声音骨架。

沙姬站上宣誓位置，却没有只说体育精神。她用华丽而自恋的修辞赞美自己，最后点名菈菈，公开发誓绝不会输给她。菈菈没有感到敌意，反而觉得大家都很有精神、这场活动很好玩；沙姬越认真，菈菈越自然，这种温差继续延续第五集建立的竞争关系。

正式改编的 User 有限赌注应放在宣战之后另行提出，不能假装原版宣誓已经拿 User 当奖品。沙姬是提议者，菈菈只能答应参加竞争，User 必须拥有独立答复页面或明确对白。

### 3. 校长的奇怪热身把赛事第一次带歪

正式比赛前，校长带领全校做自己设计的热身动作。原版逐步把动作引向对女学生身体的窥视和指挥，学生很快察觉不对并拒绝继续。

这一段可以保留“校长胡编热身—学生当场制止—猿山还想把混乱圆成赛事效果”的因果，但不能复述或细写针对未成年人的身体指令。目标版本中，校长一越界便应被学生、御门或赛事人员打断、静音或撤下领操位置；笑点落在他的企图立刻失败，而不是让他如愿获得观看机会。

### 4. 借物赛开跑：连向 User 单方面挑战，弄光把比赛当成求爱舞台

第一项是借物竞赛，猿山继续担任主解说，骨川老师一类嘉宾评论员则用古典故事和恋爱典故解释赛制。弄光先辈先夸口要创世界纪录；连又在起跑前点名原作梨斗，单方面说要为了菈菈与他决胜。梨斗立即反对把人擅自当成胜负对象，菈菈本人也没有把这项挑战当作有效归属判定。

连抽到的是“世界某处的传说之剑”。他真的冲出校门去寻找，完全无视借物竞赛应该在短时间内回场。这个看似脱线的离场必须保留，因为下午接力赛时他仍未归队，而最后带回的剑又直接造成地裂。

弄光抽到“那一天萌生的爱”一类题目，便跑去向菈菈搭讪，声称想借走她的感情，甚至可以永久保管。菈菈当场明确拒绝。猿山与旁边的跟班继续用体育转播腔解释一次彻底失败的求爱，维持本集“所有人都把私欲说成比赛战术”的笑点。

### 5. 原版露骨借物题与“推推装置”把所有参赛者一起淘汰

原作梨斗抽到的是刚被女学生穿过的运动短裤一类题目。他拒绝或无法行动，菈菈便拿出社区英译为 `Mister Push-Push` 的装置帮忙。社区剧情与截图复盘把随后无对白动作定位为：装置把梨斗推向春菜，他意外扯下她的运动短裤、挨打后飞出赛场。与此同时，连早已跑出学校、弄光也偏离项目，参赛者全部被判失格。运动短裤被扯下与挨打的精确构图仍须直接看片，但不能因为目标版要安全改写，就从原版证据层抹掉这段标志性事故。

目标改编不能把这项借物要求和公共碰撞按原样复制。安全替代应保留“题目荒唐—User 不愿照做—菈菈误以为只要推一把就能解决—装置失控—全员失格”的完整节奏，但把借物改成刚使用过的应援头带、签名号码布或其他不涉及贴身衣物的比赛道具。推力事故可以让 User 淋到水、弄坏外层运动服或与某位角色短促撞近，但不制造女学生公开衣物事故，也不替 User 写成主动占便宜。

### 6. 恋爱障碍赛把“未来人生”真的摆上跑道，菈菈最简单地赢了

下一项是女学生障碍赛，赛道却不是栏架，而是被称为“恋爱道路上的障碍”的情景剧。选手先被家长、家庭与关系危机一类夸张演员拦住；春菜面对突然塞来的混乱未来情景无法继续。沙姬则被告知自己的对象将长期服刑，听到要等待二十年后立刻计算年龄，最终也退出或被判失败。后面又出现债务、催讨等越来越离谱的成人关系难题。

菈菈没有陪演员争论，而是直接把妨碍前进的布景或演员清开，率先越过终点。沙姬不承认这是能力差距，只把失败归为个人项目运气不好，并宣告下一项一定会赢。御门凉子在被请来评论这些荒唐情景后只说自己受够了，随后离开评论席；猿山则仍能把她的退场包装成神秘而成熟的点评。

正式改编可保留“恋爱难题被实体化”的荒诞，不需要复述强迫劳动、身体偿债或针对女性的贬损台词。重点是春菜和沙姬都被过度复杂的假未来卡住，菈菈却用最直接的方式清场。

### 7. 下午混合接力：菈菈不参赛，User 与春菜同队，唯被失踪的连拖累

下午举行男女混合接力。沙姬以为终于能在团体项目与菈菈正面对决，菈菈却站在场边给原作梨斗与春菜加油，没有参加这一棒。沙姬再次因为对手没按自己预想行动而扑空。

原作梨斗与春菜处于同一接力链，原作梨斗又开始幻想两人若共同获胜，也许能自然拉近关系；这份内心不能直接移植给 User。正式改编只固定两人一起参赛、需要交接与配合的外部事实，User 对春菜的态度仍由玩家决定。

唯在红队跑出明显领先，本想证明认真比赛的价值，却发现下一棒连根本不在接力区。此前那个“传说之剑”任务终于回收：连还在校外找剑，导致整队从第一跌到最后。唯的纪律吐槽和怒气有明确原因，不能因为她只是本集配角便删掉。

### 8. 连带着真正的剑回归，地裂让接力赛直接取消

连终于扛着传说之剑赶回操场，兴奋地说要一路跑到终点。沉重武器拖慢交棒，还在混乱中释放出超出体育祭尺度的力量，操场或赛道被劈出裂缝。原作梨斗、春菜与其他参赛者被地裂卷入；社区剧情还把坠落后的无对白动作定位为梨斗误触春菜胸部并挨打。接力赛只能取消，梨斗也因此更确信春菜已经讨厌自己。误触与挨打的具体姿势仍待正片核图。

这不是一段可以随便换成普通摔倒的过场。借物赛中“连认真跑去找世界某处的剑”，必须在这里以“真带回一把危险得离谱的剑”回收；唯的领先被浪费、User 与春菜陷入事故、下一场又有人受伤缺席，都由这条因果引出。谁与谁在裂缝边准确相撞、春菜何时失去意识仍须看片确认。

### 9. User 被临时补进春菜的骑马战队，沙姬却把操场升成瞬间泳池

接力取消后，原作梨斗因再次把春菜卷入事故而消沉。有人告诉他，原定参加混合骑马战的一名学生已经受伤，需要他补进春菜所在的小队。两人短暂约定一起努力，但梨斗的尴尬和春菜的真实想法仍没有说开。

骑马战即将开始，沙姬忽然叫停。凛与绫启动天条院集团技术，操场出现巨大瞬间泳池；沙姬宣布最终项目改成水上骑马战，逼菈菈在她准备好的环境中决胜。原版校长因为想看泳装便批准改规则，这个因果不能照搬成目标版的合法决定。

正式改编中，赛事方只有在确认水深、护具、救生和普通运动装备安全后才能批准变更；校长的越界意见必须被撤麦。更重要的是，前面即使 User 已同意“胜者可优先邀请一次”的附加赌注，泳池、科技装置和风险等级都已实质变化，因此必须向 User 发起第二次确认。User 不再同意时，附加赌注作废，但沙姬与菈菈仍可继续争比赛胜负。

### 10. 沙姬以裁断装置作弊，凛与绫警告危险，菈菈靠沛凯继续比赛

水上骑马战开始后，沙姬把胜负看成终于能证明自己的机会。她与凛、绫组成的队伍亮出天条院集团装置；原版装置专门裁开对手泳装，想迫使女学生用手遮挡、无法继续抢头带。菈菈第一次被命中后让沛凯恢复服装，沙姬便继续增加发射数量。约 18:45–18:52 的混乱蒙太奇中，社区截图复盘还旁证男形连切换成女形伦；当前只记录形态切换，不断言切割器直接导致喷嚏或变身。

凛与绫很快发现飞行装置已经失控，明确提醒沙姬不能再继续。沙姬却因为执着于击败菈菈而拒绝停手，结果投射物飞向整个场地，比赛从不公平战术升级成安全事故。春菜在混乱中受到冲击或失去意识，原作梨斗将她带离赛场；准确击中顺序等待画面核对。

目标版本应把“泳装裁断器”改成 **头带、号码布或安全内层之外的外层队服裁断器**。普通女学生只发生比赛装备掉落、被判出局或慌忙避让，不出现集体脱衣。失控装置可以划破 User 的外层运动夹克、号码布或护具并把他溅湿，安全内层始终完整；沙姬停下来靠近检查、递毛巾或嘴硬地确认 User 没受伤，可以成为只面向 User 的路线种子，但不能自动增加好感或强迫亲密。

沛凯的对应职能也改成修复菈菈的外层队服、头带或比赛装备，使沙姬的战术失效。这样仍保留“沙姬以专用科技作弊—沛凯即时修复—沙姬加码—装置失控”的完整攻防。

### 11. 菈菈队夺走胜标，沙姬失败后仍启动天条院巨型大玉（滚球）

装置失控造成空当，菈菈队把握机会夺下沙姬队的目标物。猿山宣布菈菈一方赢得水上骑马战，红队也取得体育祭胜利。沙姬难以接受结果，却没有因此变成彻底恶人；她仍以“还没有结束”的气势推出天条院集团引以为豪的巨型大玉（滚球），试图再争一次面子。

滚球很快再次脱离控制，冲向校舍。这里应该保留沙姬“每次想靠更大的排场挽回输局，反而制造更大的现实损失”的人物喜剧。目标路线种子不是让她靠作弊赢得 User，而是让她在失败和事故后仍遵守 User 的答复：不宣称已经得到 User，不强行兑现邀约，最多留下“下次会堂堂正正邀请你”或“这场还没完”的后续入口。

### 12. 保健室的安静机会刚出现，就被滚球与菈菈一起撞碎

春菜醒来时发现自己在保健室，询问是不是原作梨斗把她送来。两人都为当天连续发生的误会和事故道歉，气氛第一次安静下来。梨斗把这看成终于能说些什么的机会；春菜也似乎还有未说完的话。

巨型大玉随即撞破保健室墙壁。社区截图复盘把冲击后的无对白构图定位为原作梨斗与春菜最后一次暧昧身体事故；菈菈坐在大玉上兴冲冲地出现，宣布自己赢了骑马战。墙壁破坏、两人的准确姿势和菈菈座位仍须直接看片，但原版的“终于安静—大玉闯入—身体事故—菈菈报喜”顺序必须先如实记录。

正式改编可保留 User 陪春菜到保健室、双方互相关心、短暂靠近和对话停顿；大玉冲击也可把两人撞近，或再次弄乱 User 的外层运动服，作为只面向 User 的非露骨身体喜剧。安全内层与遮挡必须完整，不能替 User 固定告白意图，也不能替春菜完成恋爱确认。大玉打断后即结束第十二集，不进入第十三集戴比路克王来访。

## 主要因果链

1. 体育祭给原作梨斗一个向春菜表现的机会，也给沙姬一个公开击败菈菈的舞台；猿山以总解说身份把整天串起来。
2. 沙姬在运动员宣誓时点名菈菈；目标适配随后增加“赛后一次邀约优先权”的有限赌注，但必须先取得 User 同意。
3. 校长的奇怪热身第一次把比赛带歪；越界意图被学生制止，而非获得成功福利。
4. 借物赛中连单方面挑战 User，又为传说之剑离场；弄光向菈菈搭讪失败，User 被菈菈的推力装置送出场，最终全员失格。
5. 恋爱障碍赛以荒唐人生难题淘汰春菜和沙姬，菈菈直接清开障碍获胜；沙姬把失败归因于运气，继续等待团体赛翻盘。
6. 混合接力中唯取得领先，却因连仍在找剑而无人接棒；连带剑回场后制造地裂，使接力取消并造成新的受伤与误会。
7. User 被补进春菜的骑马战队；沙姬突然把操场改成泳池，实质改变比赛风险，因此目标适配必须再次询问 User 是否维持附加赌注。
8. 沙姬使用裁断装置，沛凯修复装备；凛与绫劝停无效，装置失控。目标版本把公共泳装切割改成外层比赛装备事故，轻度湿身和外层破损只落到 User。
9. 菈菈队利用空当夺标取胜；沙姬再启动巨型滚球挽回面子，却让滚球冲向校舍。
10. User 与春菜在保健室互相道歉，刚出现安静的关系机会，滚球和报喜的菈菈便一起闯入，把整天重新推回猿山式体育祭混乱。

## 三条改编重点

### 一、沙姬的“可攻略”是路线种子，不是自动恋爱或运行时解锁

沙姬在第五集和第八集已经会把 User 当作刺激菈菈的竞争筹码，但现有角色稿明确禁止据此推导“她早就爱上 User”。第十二集的新阶段，应通过她是否承认 User 有选择权来表现：

- 她仍会高调提出胜负和赌注，保留大小姐式自信；
- 她必须亲口问 User 是否愿意加入附加条件；
- User 限缩条件或拒绝时，她可以嘴硬、不甘，却不能擅自覆盖答案；
- 装置失控波及 User 后，她会暂停竞争确认安全，而不是继续把人当道具；
- 失败后她遵守约定，不宣布“User 已归谁所有”，只留下以后正式邀请或再挑战的可能。

这足以让沙姬成为有独立路线潜力的角色：她的吸引力来自强势、好胜、排场、失败后的嘴硬，以及逐步学会尊重 User，而不是靠赢下一场比赛直接领取恋爱奖励。

本轮只冻结叙事资格。角色显示、地图相遇、好感值、事件解锁、档案开锁和攻略路线必须由未来运行时代码明确结算，不能由剧情正文自称完成。

### 二、User 只能是“有限邀约权”的赌注，并有两次同意门

建议把赌注写成：

> 胜者获得一次赛后优先向 User 提出喝饮料、散步、训练或庆功邀请的机会。

不能写成“胜者得到 User”“User 归胜者”“赢家自动约会”或“输家退出恋爱竞争”。完整因果需要四步：

1. 沙姬提出附加条件；
2. 菈菈只能表示自己愿意竞争；
3. User 明确选择拒绝、同意或限缩邀请种类；
4. 沙姬把赛制升级成泳池科技战后，User 再次确认是否让附加条件继续有效。

第一次同意只覆盖当时已知的普通体育祭竞争，不能自动扩张到临时泳池、飞行装置和更高风险。若 User 第二次拒绝，赌注立即作废，比赛仍按原版继续；若 User 同意，菈菈胜利后也只是取得一次“先开口”的资格，User 收到邀请时仍可以拒绝。

这两次同意都必须出现在语义验收中。菈菈的婚约主张、沙姬的大小姐宣言、猿山的夸张播报或比赛结果，都不能替代 User 本人的答复。

### 三、不能完全去福利，但福利只面向 User，User 自己也可少量卖肉

原版把借物题、校长评论、泳装和裁断器同时提供给全校围观，目标企划不采用这种公共男性凝视。安全改写也不能把整集削成只有比分的说明文，至少保留一组 User 亲身承受的轻度身体喜剧：

- 泳池或装置水花让 User 湿身；
- 外层运动夹克、号码布、头带或护具被划坏，安全内层完整；
- User 或女主角为避免摔倒而短促拉住对方；
- 女主角若发生外层比赛装备滑移、遮挡或狼狈，只让近在身边的 User 看见并协助挡住，广播、观众与路人没有观看回报；
- 沙姬、菈菈或春菜只对 User 递毛巾、整理外层装备或近距离确认是否受伤；
- 保健室对话保留停顿、距离和互相关心，但不写身体特写。

普通学生可以穿正常比赛服、参加水上项目并被水溅到，这本身不是卖肉；禁止的是将女学生的衣物破坏、遮挡动作、身体反应或湿身特写提供给校长、猿山、弄光、男生群体、摄影者和路人观看。猿山可以完整播报装置乱飞、队伍出局和校舍受损，却不描述身体，不享受事故，也不把越界包装成奖励。

所有参与体育祭的学生按未成年人边界处理。即使场景只面向 User，也只允许全覆盖、非露骨、可随时停止的轻度身体喜剧；“只给 User”并不放宽裸体、内衣、性化触摸或羞辱描写。

## 猿山为什么是本集不可替代的喜剧骨架

### 1. 他把沙姬的私人宣战包装成全校级青春决战

沙姬宣誓的内容早已偏离体育精神，猿山却用赛事主持口吻把她对菈菈的挑战说成赌上青春的精彩开幕。观众因此知道：今天无论发生什么，他都会努力当成一场正规比赛继续播。

### 2. 他不断为不可能的项目寻找“专业解释”

传说之剑、萌生的爱、荒唐借物、恋爱障碍剧场都明显不属于普通体育祭。猿山的笑点不是比项目更下流，而是始终保持播音员节奏，报出抽签、领先、退场、失格和评论员意见，让荒诞获得虚假的正式感。

### 3. 评论员不断退出，只有他还在岗位上

骨川老师把什么都讲成古典故事，御门凉子面对荒唐人生剧场说“受够了”便离开，校长又不断试图把话题带歪。猿山负责接住每次冷场、快速宣布替补评论员，再把镜头拉回下一项目。他是串场者，不是校长式福利接收者。

### 4. 他让借物赛伏笔、接力回收和水上决赛属于同一场体育祭

连离场找剑时，猿山播报他离开操场；接力缺棒时，又由解说提醒大家连仍在找剑；连带剑回来造成地裂后，他继续报告赛事取消；泳池出现后，他仍把突然改变的规则播成下一项。没有这条声音线，整集会像几段无关事故拼接。

### 5. 最终胜负必须由猿山宣布，沙姬的失败才有公开重量

菈菈夺标后，猿山宣布水上骑马战和红队胜利。沙姬随后仍想靠巨型滚球翻盘，才显得是她不愿接受已经公开落定的结果。若把解说删掉或交给泛旁白，沙姬最后一次加码也会失去喜剧压力。

因此，后续语义验收应有一个最小反例：候选保留全部比赛、User 双重同意、沙姬路线种子、安全轻福利、菈菈胜利和保健室结尾，也保留猿山自报、播出借物卡与连离场、叫担架、宣布全员失格、切换副解说、报告名次、取消接力、邀请 User 补位、转述泳池规则和宣布胜负等中性功能台词；唯一删掉的是他贯穿项目的热血实况、比分追踪、灾难包装与强行圆场。即使离散因果仍完整，该候选也必须拒绝。

## 角色、资产与注册缺口

### 沙姬当前只有档案身份与恢复稿，没有可攻略运行时

- 项目稳定 ID 可使用 `saki`，人物档案将她放在第 16 槽；显示名采用“天条院沙姬”。
- 已有 `data/lore-books/tolove-character-saki.txt`，但内容只冻结到第五集，尚未包含第十二集路线种子、双重同意和玩家定向轻福利边界。
- 已有 `artsource/ui/archive/icon_data16a.png`、`icon_data16b.png` 与 `cursor_data16.png` 三项档案 UI 素材。现有验收记录说明它们是依参考生成的 Q 版档案素材，不是官方提取立绘，也不能证明 GAL 演出可用。
- `data/default-cards/` 没有 `saki.json`，`stores/characterStore.ts` 也没有沙姬目标；因此她现在没有实际好感、友情、恋爱数值入口。
- `GalMainStory/characters/` 没有 `saki.ts`，也没有已确认的沙姬分层立绘、眼嘴表情集或专用 PNG 姓名牌。数字文件或档案图存在不能替代角色模块。

### 可用性规则存在未来接入陷阱

- `data/characterAvailability.ts` 当前没有 `saki` 规则；沙姬档案保持锁定，主要因为没有匹配角色卡，而不是因为系统已有“第十二集后解锁”的明确合同。
- 该文件对未知角色 ID 会按可见处理。因此未来若只新增 `saki.json` 而不同时加入显式规则，沙姬可能从开局意外显示。
- 真正接入时应由程序明确类似“第十二集完成后可见／可交谈”的规则，并让初始关系值保持权威默认；本研究稿不创建该规则，也不声称它已经存在。

### 第十二集仍缺少完整生产包

- 当前 `GalMainStory/episodes/index.ts` 只注册第一至第四集，没有第十二集 acts、episode index 或生产注册项。
- 没有第十二集世界书恢复源、幕边界、游戏内日期、触发行动、时间成本、场景合同和状态结算。
- 当前场景注册没有运动场／体育祭专用场景；瞬间泳池、赛道、保健室终场和校舍受损也未完成本集可用性核对。
- 猿山没有独立分层角色模块、立绘或姓名牌，但项目允许未登记人物以真实姓名使用通用文字名牌，第一集已经这样使用过他。因而未来可以保留完整解说，不需要为研究稿虚构猿山立绘。
- 唯、沙姬、凛、绫、连／伦、御门、弄光和校长在本集出现，不等于这些角色都已拥有可用角色模块。正式注册前必须按实际演员表与通用名牌规则逐一核对。

综上，本轮最强接通标签仍是：**未注册的第十二集研究与适配边界稿**。它能支持后续证据包、时间锚点和人工剧情审阅，不能证明沙姬已在地图、档案、角色卡、世界书或 GAL 主线中解锁。

## 直接看片时优先核对

- 开场原作梨斗幻想春菜加油的构图、结束方式，以及现实中由谁先与他对话。
- 猿山自我介绍、运动员入场、沙姬宣誓和各次转场中一共承担多少句解说；哪些句子来自副评论员。
- 校长热身的准确顺序、学生何时拒绝，以及目标版可抽取的最小“越界—制止”动作。
- 借物赛参赛名单、弄光先辈全名、骨川老师姓名、连点名挑战的准确措辞，以及菈菈和 User 各自如何反对“争夺菈菈”。
- 连抽到“传说之剑”的题签原文、离开操场的路线和猿山如何播报；下午带回的剑是否与题签有画面对应。
- 原作梨斗抽到的露骨借物题原文、推推装置日文名、推动路线、实际碰撞对象和全员失格判定顺序。正式适配只提取安全因果。
- 恋爱障碍赛每位选手面对的情景、沙姬的二十年／年龄计算、后续债务情景属于谁，以及菈菈如何清场。
- 御门接替评论、说“受够了”和退出的准确时点；校长何时重新成为评论员。
- 混合接力各棒顺序、唯的队伍、连缺席导致的名次变化、传说之剑如何触发地裂，以及 User 与春菜受伤的准确构图。
- 原定骑马战缺席者姓名、User 被补入哪一队、春菜在队内的准确位置。
- 瞬间泳池出现的机械过程、规则由谁批准、普通参赛服与水上比赛装备的画面；目标版不保留校长因泳装批准的因果。
- 沙姬装置的日文名、发射物、目标、凛与绫各自操作和劝停台词、沛凯修复方式，以及菈菈夺标的准确瞬间。
- User 与春菜何时离开赛场、春菜失去意识的直接原因、User 是独自抱送还是与他人协助送医；正式适配保持照看但避免未经确认的身体构图。
- 沙姬巨型滚球的启动、失控路线、撞击位置，以及它与保健室打断之间的空间因果。
- 保健室中春菜醒来、互相道歉、即将继续说话、滚球撞入和菈菈报喜的逐句顺序；结尾不要误接第十三集预告。
