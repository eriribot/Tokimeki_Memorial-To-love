# 第十一集剧情整理：金色暗影“小暗”登场与第一次动摇

## 结论先行

第十一集登场的是 **金色暗影（原文：金色の闇／Golden Darkness）**。这是她作为宇宙杀手使用的代号；菈菈在本集中以 **小暗（ヤミちゃん）** 称呼她，并在终场说明这个亲昵称呼来自“闇”。本集没有确认她的真实姓名，更不能因为项目旧卡借用了《BLACK CAT》的设计来源，就把“伊芙”写成她在《To LOVE-Ru》正片里自报的名字。

小暗初登场的核心也不只是“来杀主角又没杀成”，而是她第一次发现三件事互相冲突：

> User 先把鲷鱼烧分给她、遇袭后也不还手；菈菈坚持 User 不是委托资料所说的极恶之徒；委托人拉可斯波现身后，又亲口暴露雇凶是为了抢走菈菈，并无法解释假情报。

这条怀疑最终被两次保护和一句“可爱”推进：菈菈替小暗挡下恶意攻击，User 又保护菈菈，菈菈击退拉可斯波后第一次把小暗当成普通女孩看待。小暗最后仍说自己不会放弃已经接受的任务，会留在地球继续把 User 当目标；但菈菈随即邀请她交朋友，她答应了。**任务没有正式取消，友情也没有被否定，两者在结尾同时成立。**

## 名称与身份口径

能安全采用的写法是：

- `金色の闇／金色暗影` 是她广为人知的宇宙杀手代号；
- 菈菈在本集中使用 `小暗／ヤミちゃん` 这一昵称，终场说明昵称由来，小暗没有拒绝；
- 她能发动变身（Trans）能力，把身体部位自由变化成武器；
- 她自称与目标没有私怨，只是在履行受托的工作；
- 她把准确目标资料和完成委托视为职业原则；
- 鲷鱼烧、对越界行为的厌恶、孤独生活和第一次被称作可爱，都在本集留下了以后会反复回收的种子。

不能直接采用的写法是：

- “她的真实姓名就是伊芙”。项目旧卡中的“伊芙”是跨作品设计来源混用，不是本集自报名；
- “小暗从一开始就是大家都知道的本名”。这是菈菈根据代号产生的昵称；
- “她见到鲷鱼烧就已经确认这是最爱”。本集只演到第一次接受和记住这份食物；
- “她结尾正式放弃任务、成为学生并解锁恋爱路线”。她明确仍把主角视为目标，只是留下并答应交朋友；
- “她因被打败才服从菈菈”。真正变化来自委托资料崩塌、互相保护和第一次被善意看见。

## 按时间顺序整理的剧情

### 1. 金发少女降临和平地球，结城家却在举行零用钱仪式

一名小柄金发少女从空中降临，站在高处观察城市，淡淡评价这是个和平的星球。她的冷静登场把危险先放在画面外，观众尚不知道她的身份和任务。

同一时间，结城家正进行极有仪式感的零用钱发放。萨斯丁把菈菈当月零用钱交给她，还提醒她别乱买无用物品。美柑说明原作梨斗已经被自己派出去跑腿购物，又突然想起漏买的一项；菈菈和萨斯丁准备去追，却被家庭式混乱拖慢。

这一段把小暗的专业冷感与结城家的日常闹剧并置，也给主角独自在街上遇见她创造条件。

### 2. 原作梨斗偶遇春菜，短暂购物约会后再次错过机会

原作梨斗完成美柑交代的采购时，偶然遇见也在购物的春菜。两人都想开口又互相迟疑，最后由梨斗提出帮她拿东西，春菜欣然接受。梨斗把这段同行当成小小约会，心里注意着春菜的可爱。

春菜的朋友很快出现并邀请她继续同行。梨斗认为自己留下会碍事，又还有采购要完成，于是先行离开；双方只约定“下次”。这段并不参与暗杀主线，只用平静、青涩的日常衬托几分钟后突然出现的杀手。

正式改编时，可以保留 User 与春菜一起购物和错过进一步同行的外部顺序，但不能替 User 固定“约会成功”、爱慕独白、遗憾程度或下一次邀约。

### 3. 一枚鲷鱼烧建立了小暗对目标的第一份亲眼证据

采购完成后，原作梨斗买了鲷鱼烧。回家途中，他注意到那名金发少女一直盯着自己或手中的食物，便主动分给她一个。少女接过并吃下，只评价地球食物很奇怪。

这不是随手可删的萌点。她接到的委托把目标描述成极恶之徒，但她真正接触目标后的第一件事，却是对方没有戒备地分享食物。后面她质疑资料时，Fandom 明确把这次鲷鱼烧回忆作为判断依据；即使正式改编不写内心独白，也必须让这一事实可被她记住。

### 4. 少女确认目标并宣布暗杀，温和相遇瞬间翻面

少女问他是否就是结城梨斗，得到确认后立刻把手臂或身体部位变成武器发动攻击。她说明某人委托自己消灭他，自己与目标没有私怨，只是执行工作。

原作梨斗躲开并逃跑，没有反击。小暗一边追击，一边困惑他为什么不还手；她还根据情报把他称作可怕恶徒，却又承认眼前的人看起来不像。这是委托资料第一次出现裂缝，并非等到菈菈说明后她才被动怀疑。

正式改编时，结城梨斗姓名与暗杀目标位置全部映射为 User，企划中不能再出现另一个男性梨斗。User 的恐惧、勇敢、是否尝试对话和具体逃跑方式仍属于玩家表达。

### 5. 萨斯丁拦截，御门凉子说出“金色暗影”与 Trans 能力

小暗准备结束追杀时，萨斯丁及时以剑挡下攻击，自报自己是戴比路克王室卫队长，也顺带负责保护准驸马。两人随即交手。

菈菈赶到主角身边，御门凉子也在附近出现。凉子认出少女的代号是“金色暗影”，说明她是能够把身体任意部位变成武器的宇宙杀手，并建议众人不要卷入；她还以校医式口吻留下“受伤可以找我”的轻描淡写笑点。

萨斯丁看似准备靠地球环境取得优势，最终却因井口或地面机关意外掉下去。这个退场不是小暗被击败，也不代表萨斯丁毫无战力；它让保护主角的核心位置转交给菈菈。

### 6. 菈菈主动挑战小暗，战斗却不断被地球式低俗误会打断

萨斯丁退场后，菈菈主动宣布由自己接战。小暗提醒她自己不擅长手下留情，菈菈则对自己的力量很有信心。两人的战斗快速穿过街区并造成破坏，原作梨斗还被波及到公共浴场，引发一次被当成闯入者的误会。

菈菈接连使用黏着发射器、抓取机械手和旋转绳索一类发明，却因为准头、路人干扰或小暗的反应而没有真正制伏她。校长看到小暗后又作出窥视和骚扰式举动；小暗明确表示厌恶好色或越界行为并猛烈反击。这为她以后反复出现的“讨厌 H”式反应建立本集来源。

这些桥段可以中性记录其喜剧职能，但正式改编不得把澡堂、衣物或校长骚扰扩写成对未成年角色身体的细致展示。重点是误会、越界和小暗主动反击。

### 7. 小暗复述假情报，也第一次说出独自在宇宙生活的孤独

小暗问菈菈为什么要保护 User。根据委托人提供的资料，目标不仅威胁和囚禁菈菈，还准备夺取戴比路克的统治权。菈菈马上否认：User 根本不是那种人。

小暗把眼前的不还手、此前分来的鲷鱼烧和菈菈的证词放在一起，已经倾向于相信资料存在问题。但她仍强调，自己会消灭接下工作所指定的对象，因为这就是“金色暗影”的生存方式。她还认为从小在宫殿受保护的公主不会理解独自在宇宙中生活的孤独。

菈菈没有用身份压服她，而是说自己正因为对宫殿外的世界所知太少，才主动离家来到地球。两人第一次不再只是公主与杀手，而是在“离开原有世界、重新理解生活”上碰到共同语言。

### 8. 拉可斯波延后登场，亲自揭穿委托人的私欲

战斗正要继续时，一艘飞船出现，拉可斯波从中现身。他命令金色暗影不要再和菈菈纠缠，赶紧消灭真正目标。

菈菈由此确认拉可斯波就是委托人。拉可斯波承认自己雇凶是为了除去菈菈的婚约对象，再让菈菈嫁给自己；菈菈不仅拒绝，还明确认为为了求婚而杀害 User 的行为卑劣残酷。

TV 版直到此处才揭露委托人，因此前半集保留了“谁想杀主角”的悬念。不能按漫画顺序把拉可斯波提前通话和自白插回 TV 开场。

### 9. 小暗不是被说服倒戈，而是独立向不诚实的委托人问责

拉可斯波转而责骂小暗没有及时完成任务。小暗却正好要找他谈话：自己实际观察到的 User 与委托资料差距很大，而执行任务需要准确情报；她直接质问拉可斯波是否欺骗了自己。

拉可斯波无法给出可信解释，只重复 User 欺骗了菈菈，并把“我是雇主”当作要求服从的理由。小暗冷冷审视他，表明即使仍重视契约，她也有自己的职业判断，不是付钱者说什么就照单全收的工具。

这个因果必须由小暗本人拥有。User 的善意和菈菈的证词提供证据，但“发现情报失实—质问委托人”的决定不能交给 User、菈菈或御门替她完成。

### 10. 拉可斯波召出巨蛙，把失控委托升级成对小暗的惩罚

拉可斯波见小暗可能抗命，直接威胁处置她，并召出巨型宠物蛙 Gama-Tan。沛凯认出这种生物：它的黏液几乎不伤其他东西，却能破坏衣物，也是沛凯惧怕的天敌式存在。

小暗尝试以武器化能力反击，却无法轻易切开黏液；拉可斯波还公开把破坏她衣物当作羞辱和惩罚。这里已经不是委托人与杀手的正常争执，而是拉可斯波为掩盖谎言、强迫服从而转向攻击自己的受托者。

巨蛙种族名在不同社区资料里出现 `Irogaama`、近似拼法或意译冲突。当前只使用正片稳定出现的宠物名 `Gama-Tan／ガマたん` 和“黏液破坏衣物”的效果，不硬化种族拼写。

### 11. “菈菈护小暗—User 护菈菈—菈菈终结威胁”形成互相见证

拉可斯波命令巨蛙从后方攻击小暗时，菈菈主动挡在她面前，替这个刚才还要杀 User 的敌人承受攻击。拉可斯波又想继续羞辱菈菈，User 终于直接介入：挡在她前面或冲向威胁，怒斥并击打拉可斯波。

巨蛙把 User 击开，又准备进一步攻击；沛凯恢复菈菈的防护或服装状态后，菈菈连续反击，把巨蛙和拉可斯波一起送回飞船或击飞。

这段不是“User 一个人打败所有人”，也不是“菈菈单方面救小暗”。三个动作有不同所有者：

1. 菈菈不计敌我，先保护遭到不义攻击的小暗；
2. User 看到菈菈被羞辱和伤害后，主动保护菈菈并反击拉可斯波；
3. 菈菈在最后危险到来时完成终结，击退巨蛙与委托人。

小暗正是在旁亲眼看见这条互相保护链，进一步确认“威胁公主的极恶之徒”资料不可信。

### 12. 第一次被说“可爱”，“小暗”称呼的由来也被说开

敌人离开后，小暗问菈菈为什么要救一个敌人。菈菈的答案非常直接：做坏事的是拉可斯波，她不能原谅对方欺负像小暗这样可爱的女孩子。

小暗明显被“可爱”触动，因为此前从来没有人这样评价过她。紧接着，User 又问菈菈为什么一直用“暗／Darkness”称呼她；菈菈解释自己把“金色暗影”当作名字，所以一直使用带亲昵感的“小暗／ヤミちゃん”。小暗说叫什么都无所谓，没有拒绝这个称呼。21:06 这一段确认的是昵称由来和她的允许；昵称在本集第一次出现的准确时刻仍待日语正片核定。

这一刻不是揭露真名，而是身份关系发生细小变化：别人第一次没有把她只当武器、代号或雇佣对象，而是把她当一个“可爱的女孩”，并把原本冷硬的代号作为可亲近的昵称继续使用。

### 13. 她仍把 User 当目标，却以“朋友”身份留在地球

User 认为拉可斯波已经被击退，便建议小暗停止追杀、回到宇宙。小暗听到“回去”时出现短暂停顿，随后以职业原则回答：自己不会半途放弃已经接受的工作，因此会留在地球，直到亲手消灭 User。

这句话表面仍是威胁，也替她留下提供了不暴露脆弱的理由。正片在此没有宣布任务取消，没有交代她正式住址，也没有安排她马上入学。

菈菈却把“她会留在地球”直接理解成可以继续来往，于是邀请小暗成为朋友。小暗简短答应，整集到此结束。结尾的魅力就在于两条看似矛盾的身份同时保留：

- User 仍是她声称要消灭的工作目标；
- 菈菈已经把她视为朋友，她也接受了这份关系。

后续改编不能为了方便解锁角色，就把这份开放矛盾压扁成“洗白加入队伍”或“暗杀任务彻底结束”。

## 主要因果链

1. 金色暗影降临地球；美柑派原作梨斗购物，使他独自在街上行动。
2. 梨斗与春菜短暂同行后分开，在回家路上把鲷鱼烧分给陌生的小暗。
3. 小暗确认目标并发动暗杀；梨斗只躲避、不反击，使她第一次怀疑“极恶之徒”资料。
4. 萨斯丁挡下攻击，御门说明金色暗影和 Trans 能力；萨斯丁意外退场，菈菈主动接战。
5. 战斗中的澡堂误会、发明失误和校长越界建立小暗讨厌好色行为的反应。
6. 小暗复述“User 威胁菈菈、企图夺取戴比路克”的委托资料；菈菈否认，她又想起鲷鱼烧，却仍坚持职业原则，并谈及独自在宇宙的孤独。
7. 拉可斯波现身，承认为了娶菈菈而雇凶；菈菈拒绝，小暗则独立质问他提供假情报。
8. 拉可斯波转而攻击小暗；菈菈替小暗挡下巨蛙攻击，User 再保护菈菈，菈菈最终击退巨蛙和委托人。
9. 菈菈称小暗可爱，解释“小暗”昵称的由来并得到她允许，使她第一次被当成普通女孩看见。
10. 小暗以完成工作为由留下，仍称 User 为目标；菈菈提出交朋友，小暗答应，在未消解矛盾的状态下完成登场。

## 小暗初登场究竟确立了什么

- 公开身份：她是以“金色暗影”为代号活动的宇宙杀手，而不是名叫“金色暗影”的普通学生。
- 核心能力：变身（Trans），能够把身体部位变化成刀刃、翅膀或其他武器；本集出现的每种形态仍待画面逐项确认。
- 职业原则：接受任务后不轻易放弃，同时要求委托人提供准确资料；她服从契约，但不是放弃独立判断的工具。
- 观察能力：User 不还手、先分享鲷鱼烧和菈菈的证词都会进入她对目标的重新判断。
- 行为边界：她明确厌恶好色、窥视和越界行为，会迅速反击。
- 情感缺口：她习惯独自在宇宙生活，第一次被人说可爱，也没有拒绝“小暗”这个亲昵称呼。
- 与菈菈的起点：从交战、彼此理解到菈菈替她挡攻击，最后接受“交朋友”。
- 与 User 的起点：仍是名义上的暗杀目标；鲷鱼烧和不还手让她开始怀疑委托资料，但本集没有确立恋爱或任务取消。
- 本集没有确立：真实姓名“伊芙”、彩南高校入学、图书馆日常、长期住址、任务名存实亡、恋爱好感、角色卡解锁或 GAL 分层立绘可用。

## 三个不能删的“小暗味”锚点

### 1. 鲷鱼烧不是兴趣标签，而是她亲眼获得的反证

若先写“小暗喜欢鲷鱼烧”，再让 User 投喂，只剩角色清单式服务。正确顺序是她先作为陌生人接受食物，随后才确认送食物的人正是目标。那份毫无防备的善意与“极恶之徒”资料冲突，才让鲷鱼烧变成长期关系锚点。

### 2. 她必须亲自质问拉可斯波

小暗不是听菈菈说一句“他骗你”便立刻改阵营。她先观察目标，再听取菈菈证词，最后面对委托人核对资料并追问诚信。这是她作为职业人士和独立角色的尊严，不能让 User 拿出万能证据或替她宣布合同无效。

### 3. “继续追杀”与“答应交朋友”必须一起留下

只保留追杀宣言，会让她像没有变化；只保留交朋友，又会让转折过快。两句并列，才表现她暂时只能用职业原则解释“为什么要留下”，同时又第一次接受超出委托关系的善意。

## TV 版与漫画 Trouble 35–38 的主要差异

- 漫画中拉可斯波较早通过通讯向菈菈承认雇凶；TV 版把委托人揭露延后到约 15:51，使小暗的追杀前半段保留悬念。
- 漫画开场让原作梨斗替漫画家父亲买网点纸，并为萨斯丁买鲷鱼烧；TV 版改成替美柑跑腿，并新增与春菜共同购物的日常段落。
- 漫画包含沙姬别墅票和同学搭讪小暗等支线；TV 版删除或改写，以澡堂误会、校长和菈菈发明串起战斗喜剧。
- 漫画中萨斯丁被列车套路反噬；TV 版改成掉入井口或地面机关。不能把两种退场方式混写。
- TV 版强化了互相保护：菈菈护小暗、原作梨斗再护菈菈、菈菈最后击退敌人。
- TV 版结尾明确增加菈菈提出交朋友、小暗答应的对话；正式整理 TV 第十一集时必须保留。

上述差异来自社区章节梗概比较，不是官方逐项改编说明。若日后需要做漫画忠实路线，应另建漫画证据包，不能把两套连续性拼成一集。

## 角色职能与改编映射

- 原作结城梨斗：正式改编中由 User 承接替美柑购物、与春菜同行、把鲷鱼烧分给陌生少女、遭追杀而不还手、被萨斯丁和菈菈保护、保护菈菈并反击拉可斯波、建议小暗回宇宙等剧情位置。企划中不存在另一名男性梨斗。
- 金色暗影／小暗：保留杀手代号、Trans、职业原则、对假资料的独立判断、孤独感、被“可爱”和昵称触动、留下继续任务并接受朋友邀请。项目 ID 可以沿用 `yami`，但旧卡的“伊芙”和后期状态不能倒灌。
- 菈菈：主动保护 User、挑战小暗、否定假资料、与小暗谈离开宫殿、拒绝拉可斯波、替小暗挡攻击、终结威胁、称她可爱、说明并延续“小暗”昵称、邀请交朋友。她的保护和友善不能由 User 指挥。
- 拉可斯波：为了娶菈菈而雇凶、提供虚假目标资料、在小暗质疑后转而攻击她，并召出巨蛙。他是委托与后半危机的因果所有者，不能写成无辜传话人。
- 萨斯丁：第一次挡下小暗攻击并与她交手，随后被地球环境笑点淘汰；不能替菈菈完成主战，也不负责揭露委托人。
- 御门凉子：认出金色暗影、说明 Trans 和危险程度，并提供校医式提醒；她不参与最终战斗，也不替小暗判断资料真假。
- 春菜：只承担前段共同购物、约会感与平静日常的反差。她没有见到小暗、没有被误认成目标，也不参与暗杀事件。
- 美柑：委托 User 购物并参与结城家零用钱日常，不参与街头战斗；她与小暗的后续关系不能提前写进初登场。
- 沛凯：识别巨蛙、说明黏液效果并在关键时刻恢复菈菈的防护；不能用后来设定替代本集观察。
- 校长与公共浴场路人：只承担越界、误会和小暗反击好色行为的短笑点，不扩写露骨内容。
- 夕崎梨子：原动画本集没有对应职能。若正式适配时出现，只能按最新项目权威保留 User 青梅兼美柑姐姐的有限日常反应，不能继承暗杀目标、鲷鱼烧赠予者、春菜同行或美柑委托人的职能。
