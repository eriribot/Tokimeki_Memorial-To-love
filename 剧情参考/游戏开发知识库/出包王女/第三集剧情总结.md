# 第三集《三角关系》改编梳理

## 先把人摆正

这一版的主角是 User。User 与结城家共同生活。原作中由结城梨斗承担的主角剧情，包括菈菈的婚约关系、春菜没能说出口的在意，以及本集的事故喜剧位，都改编到 User 身上。故事里不存在另一名男性梨斗。

夕崎梨子不是梨斗的性转版本，也不替 User 走主线。她是 User 的青梅竹马，熟悉他的日常习惯，可以提醒日期、人物近况和眼前风险；她不知道没见过的事，也不能替 User 判断感情。她保有自己的生活和攻略线，作用接近一个可靠但有限的情报位。

每天虽然有两次行动，第三集的三幕都是整天主线：在当天第一次行动触发，结束后直接结算到次日。这样不用为主线硬留半天空档，也不会把同一趟出游拆成几个互相抢 AP 的小事件。

## 第一幕：4 月 11 日，转校生一点也不低调

承接第二集结尾，菈菈刚以转学生身份进班。课间，User 把她叫到天台，问她为什么突然转来，又是怎么办好手续的。

![[QQ_1785039340861.png]]

菈菈回答：“因为我想一直陪在你身边。”User 还没来得及消化，她便说自己去拜托了校长，校长因为觉得她可爱就答应了。

![[QQ_1785042064088.png]]

User 只能提醒她别太显眼，免得外星人的身份暴露。这个提醒马上被现实打脸：菈菈在课堂和体育活动里接连做出远超常识的表现，周围越聚越多人。

![[QQ_1785042162211.png|453]]

里纱和未央在这里露面。里纱一见新人就没什么距离感，未央负责及时把她拉开。保留两人的性格和同班关系即可，不把动作笑料写成身体展示。

![[QQ_1785042850779.png]]

菈菈整天黏着 User，惹得班里男生嫉妒。纸团、空盒一类东西朝 User 飞来，他被砸得狼狈，菈菈却可能还以为大家在玩。

![[QQ_1785042897803.png]]

梨子可以在校园骚动后提醒一句“你不是还要她低调吗”，帮 User 把注意力拉回眼前，但她不替他处理菈菈，也不预先知道后面的出游安排。

放学前，User 再次把菈菈带回天台，提醒她不要每次都把“低调”忘得一干二净。菈菈认真保证下次不会再犯，笑点到这里自然收住。

之后，User 和春菜终于有机会单独说话。他想解释婚约不是大家想的那样，春菜却先退了一步，说：“我觉得你们很般配。”这不是讽刺或争宠，而是春菜误会了两人的关系，又不敢把自己的心意说出来。菈菈恰好来叫 User 回家，让误会变得更难解释。

User 回家后一直没精神。美柑看出他继续闷着也想不明白，便对他说：“明天我们带菈菈出去走走吧。”第一幕只停在这个提议上，不再写入睡或跨日过程。

## 第二幕：4 月 12 日，换装、断电和服装店偶遇

第二天早上，User、美柑和菈菈一起出门。菈菈的宇宙服在人群里太扎眼，User 让她换套普通衣服，沛凯说：“装束分析完成。换装。”

沛凯照着路人的衣着连续变换，越换越离谱。正常衣服确定后，三人继续逛街；抓娃娃和菈菈珍惜兔子布偶的细节可以留下，让这段不只剩闹剧。

连续换装耗尽了沛凯的能量。它向菈菈道歉，衣服也开始不稳定。

![[QQ_1785043561025.png]]
![[QQ_1785043571097.png]]

User 和美柑挡住旁人的视线，把菈菈带进最近的服装店补救，偏偏在那里遇见春菜。

![[QQ_1785043627731.png]]

User 一时解释不清，美柑先用“陪外地朋友逛街”把现场圆过去。

![[QQ_1785043695165.png]]

接下来的邀请顺序不能换：

1. 美柑先问：“春菜姐，明天要不要也和我们一起？四个人出去会更热闹。”
2. 春菜还在犹豫，菈菈便凑过来撒娇：“来嘛，春菜！我还没去过地球的水族馆，我们明天一起去看鱼吧！”水族馆在这里才第一次成为明确目的地。
3. 美柑说明自己正好有四张票，春菜随后答应。

第二幕到“约好明天见”为止。当天没有提前进入水族馆，也不把主动邀请改成菈菈先开口。

## 第三幕：4 月 13 日，水族馆与差一点说出口的话

星期日，User、美柑、菈菈和春菜按约来到水族馆。菈菈忙着追鱼和问问题，美柑察觉 User 与春菜之间有话没说，便找个自然的理由带菈菈去另一边，把空间留给两人。美柑观察得细，但不需要被写成什么都懂的恋爱军师。

![[QQ_1785043782580.png]]

User 越紧张越想结束话题，春菜却叫住他。她先重提自己说过 User 和菈菈很般配，也承认菈菈是个很棒的女孩；话锋一转，她又说 User 同样很温柔——从初中起，他一直自发照料教室里的花，从来不是谁要求他去做。直到这时，User 才意识到春菜早就一直在关注自己。

春菜绕了一圈，又回到“你们很般配”这句话，却终于接出“即使这样，我……”；User 听懂了，也以“春菜，我也……”开口。两个人都已经走到互相表白的开头，菈菈引发的鱼群骚动却在这时打断他们。告白没有说完，关系也不在本集结算。

菈菈看见鱼没精神，拿出“狂战士 DX”让它们振作。鱼群兴奋过头，接连冲出水面。沛凯提醒她鱼离开水会死，菈菈这才第一次知道这条地球常识，于是又拿出“增水君”补水。

![[QQ_1785044664994.png]]

增水君把水族馆淹得一团乱，春菜和 User 刚刚开始的互相告白被彻底截断。骚动结束后，春菜仍说今天很开心；两人都没有补完刚才的话，本集也不把这次未完成的告白结算成交往或路线结果。

尾声落在 4 月 14 日星期一早晨，不另开第四幕，也不再消耗一次行动。User 在上学路上见到春菜，一慌便平地摔倒；讲义散了一地，梨子顺手帮他捡起几张，嘴上提醒他看路。收尾保留慌乱和碰撞，不照搬原作钻进裙底的露骨构图，摔倒后立刻结束第三集。

## 不能丢的锚点

- User 是唯一主角，与结城家共同生活；不存在男性梨斗。
- 梨子只是 User 的青梅竹马和有限情报提醒位，不继承婚约、春菜感情线或结城家兄妹关系。
- 4 月 11 日首行动是一整天：天台追问、校园骚动、春菜谈话，以及美柑提出第二天出门。
- 4 月 12 日首行动是一整天：换装、沛凯断电、服装店偶遇；美柑先邀请春菜，菈菈再撒娇并提出水族馆，春菜最后答应。
- 4 月 13 日首行动是一整天：水族馆谈话与洪水；4 月 14 日星期一的平地摔只是尾声。
- 校长因“可爱”放行，里纱与未央出场，男生因嫉妒向 User 扔杂物。
- 沛凯说“装束分析完成。换装”，连续换装导致能量耗尽。
- 美柑自然带走菈菈；春菜先重提 User 与菈菈“很般配”，再说明自己从初中起就注意到 User 无人要求也会照料教室里的花。春菜与 User 都把告白说到开头，随后被菈菈造成的事故打断。
- 狂战士 DX、鱼离开水会死、增水君和水族馆洪水都要保留。
- 不完成告白，不替 User 决定未来感情，不让模型重算 AP、日期或事件结算。
