# 第七集剧情整理：Fandom 骨架与官方资料

## 来源范围

- `official-metadata`：[TBS 第七集故事页](https://www.tbs.co.jp/anime/to-love-ru/03story/story.html)确认连是菈菈的外星青梅竹马、以“变得有男子气概就结婚”的童年约定为目标来到地球，并向梨斗宣告要夺回菈菈。
- `official-metadata`：[XEBEC 第七集介绍](https://www.production-ig.co.jp/xebec/anime/toloveru/episode07.html)确认连转入梨斗所在班级、努力证明男子气概，以及梨斗虽然厌烦这场单方面挑战，却开始在意菈菈和连的关系，并提供本集制作信息。
- `community-plot`：[All Men Should Be Like This!](https://toloveru.fandom.com/wiki/All_Men_Should_Be_Like_This%21)提供上学路遇见伦、喷嚏变身伏笔、童年照片、校内挑战、误吻、寻找“男子汉”答案、电影与训练蒙太奇、120 公里长跑和结尾身份揭示的完整骨架。
- `community-recap`：[2008 年第七集评论索引](https://www.new-akiba.com/news/to_love7_2)证明播出期评论普遍注意到连／伦的性别转换设定、训练主线和重复使用的淋浴画面；该索引主要总结当年观众评价，不能证明具体台词和动作顺序。
- 本文只整理第七集动画原剧情，不做 User 或夕崎梨子改编，不分游戏幕，不安排日期、行动点和运行时结算。
- 当前没有本集字幕、时间码或用户逐段观看校对。连、伦的中文姓名和种族译名存在版本差异，本文暂用“连（Ren）”“伦（Run）”，以后以用户所看片源字幕为准。

## 基本信息

- 集数：2008 年 TV 动画第 7 集
- 英文标题：All Men Should Be Like This!
- 日文标题：男とはかくあるべし！
- 播出日期：2008 年 5 月 15 日
- 脚本：大和屋晓
- 分镜：小坂春女
- 演出：松本マサユキ
- 作画监督：佐野阳子、本桥秀之
- 本集新增人物：连·艾尔西·裘利亚（Ren Elsie Jewelria）与伦·艾尔西·裘利亚（Run Elsie Jewelria）。两者是同一外星人的男女形态，不是双胞胎或两个同时存在的人。

## 剧情顺序

### 1. 梨斗在上学路遇见穿男生制服的少女

梨斗快要迟到时，在上学路上遇到一名穿着男生制服的漂亮少女。他提醒对方也该赶快去学校，少女却不显得着急。梨斗离开后，一只苍蝇落到少女身上或鼻子附近，使她打了喷嚏。

Fandom 随后写到校外有人注意到“她已经来了”，但没有说明观察者身份。开场没有立刻解释喷嚏的后果，只把少女、男生制服和即将出现的转学生连连在一起，作为结尾揭晓伦身份的伏笔。

### 2. 美少年转学生当众称菈菈为新娘

同一天，梨斗班里迎来名叫连的美少年转学生。班中女生很快被他的外貌吸引；连却径直走到菈菈面前，称她为自己的新娘，令全班震惊。

菈菈起初完全没认出他。连满怀期待的重逢当场落空，Fandom 用“像被陨石压扁”来形容他的夸张受创反应。这个反复出现的精神打击画面，是连越认真、菈菈越不当回事的核心笑点。

### 3. 童年照片唤回“爱哭鬼连”的记忆

猿山追问连与菈菈是什么关系。连拿出两人的童年照片，照片中的自己穿着裙子；菈菈这才想起他是小时候的玩伴，并称他为“爱哭鬼连”。

连随后回忆自己与菈菈的童年往事。他把两人的共同经历说得很珍贵，画面却显示自己经常被卷进菈菈危险的发明实验，所谓“美好回忆”带着明显的单方面滤镜。

连还坚持，菈菈小时候曾答应，只要他变得有男子气概，就会嫁给他。菈菈连这项约定也记不清，使连再次受到夸张打击。官方资料确认这个条件式童年约定是他多年努力和来到地球的根本动机。

### 4. 连用荒唐小比赛向梨斗证明男子气概

连把梨斗当作夺走菈菈的人，宣告要从他手中把菈菈“夺回来”。为了证明自己比梨斗更像男子汉，他开始不断发起或自行完成意义可疑的挑战。

Fandom 明确列出的例子包括撕碎一本漫画，以及在体育课或跑步中超过所有人。被撕的漫画据称画成《To LOVE-Ru》自身，是一个自指彩蛋。连完成每次挑战后都会追问菈菈自己是否已经足够有男子气概，菈菈却只回答“不知道”，让他一次次陷入夸张消沉。

### 5. 梨斗设想菈菈离开，又开始在意两人的关系

梨斗一度想到：如果菈菈真的喜欢上连，两人就会一起回到宇宙，自己也许能够恢复原来的生活并接近春菜。这个设想表面上正符合他一直想解除婚约的目标，他却没有因此完全轻松。

TBS 与 XEBEC 都把“梨斗不知为何在意菈菈和连的关系”列为本集人物线。这里最多能确认他开始动摇和关注，不能单凭官方短梗概直接断言他已经爱上菈菈或选择了哪一条恋爱关系。

### 6. 连与梨斗意外接吻

连找梨斗谈话时，有人从旁边撞到或推到连，使两人意外亲到一起。两人都立刻表现出强烈嫌弃和混乱。

Fandom 没有说清是谁造成碰撞、现场有哪些目击者，也没有给出这段意外在后文中的作用。当前只能把它记作连的“男子汉竞争”不断脱轨的校园笑点，不能据此建立任何恋爱关系。

### 7. 连搜集各种“真正男子汉”的意见

连续受挫后，连开始向周围人询问什么才算真正的男子汉。他收到的回答彼此矛盾或十分古怪，却把这些建议全部混在一起照做，结果只让自己看起来更加夸张。

当他再次向菈菈展示成果时，菈菈没有认可他的男子气概，只觉得他的样子很好笑。应看片确认连具体问了哪些人、每个人给了什么建议，以及他怎样把建议组合成装扮或行为；Fandom 当前没有列出明细。

### 8. 电影《男人》把连推入极端训练

无计可施的连看到影院正在播放一部名为《男人》的影片，便进场寻找答案。Fandom 指出影片是对《洛奇》系列的戏仿，并把片名写作类似 `Rocky VII` 的作品。

电影令连深受感动。他开始模仿片中的训练方式，用高强度锻炼塑造自己认定的男子汉形象。2008 年播出期评论还提到本集出现多段淋浴或冲洗训练后的画面，并有重复使用镜头的情况；具体次数、位置与是否属于同一训练蒙太奇仍需看片确认。

### 9. 连声名大振，却拒绝提前得到答案

随着训练升级，连逐渐在学校甚至更大范围内出名。梨斗眼看事情越来越失控，劝菈菈干脆告诉连“已经够有男子气概”，让这场挑战结束。

菈菈似乎愿意照做，连却拒绝接受这份提前给出的答案。他认为自己还没有达到真正男子汉的标准，必须靠更严苛的考验亲自证明。这一选择说明他并非只想从菈菈嘴里骗到一句认可，而是已经被自己的执念和电影逻辑推动得停不下来。

### 10. 从番长、雪山到赛车和摔角的超现实考验

连接下来的训练彻底离开普通校园尺度。Fandom 依次列出：

1. 挑战“西日本番长集团”。
2. 攀登冰雪覆盖的高山并与大脚怪交战。
3. 与号称世界最快赛车手的 Johnny 进行危险的胆量赛车或鸡游戏。
4. 进入摔角擂台，对付棒球选手、巨大机器人等不合常理的对手。

这些桥段很可能以电影蒙太奇和夸张新闻式剪辑快速通过，并非写实连续旅行。每段的地点、对手正式名称、胜负过程和旁观者反应都只来自 Fandom 的英文概括，应等待直接看片补足，不宜自行扩成完整冒险。

### 11. 120 公里最终长跑把连练成肌肉猛男

连把 120 公里长跑当作最后试炼。完成长跑后，他的体格已经变得异常强壮，与初登场的纤细美少年形成明显反差。

菈菈终于准备承认他有男子气概。就在连即将得到多年追求的答案时，一只苍蝇落到他鼻子上，使他打出喷嚏；从开场埋下的触发条件在最关键的时刻再次出现。

### 12. 喷嚏让连变成伦，男子汉证明当场失效

连在喷嚏后变成少女形态，正是梨斗上学路遇到的那名穿男生制服的少女伦。沛凯或菈菈随后说明，连属于能够在男女两种形态间转换的外星种族；对连／伦而言，喷嚏就是变化触发条件。

Fandom 将种族英文写作 `memorzean`，正式日文名与中文字幕译法待核对。菈菈面对少女形态的伦，表示自己无法说一个女孩子“很有男子气概”。连拼命完成的所有训练因此在最后一秒失去判定条件，本集以身份揭晓和目标再次落空收束。

## 主要因果链

1. 连为了兑现菈菈童年随口说出的条件式婚约，从宇宙来到地球，并以伦形态在上学路先与梨斗擦肩而过。
2. 他转入同班后当众称菈菈为新娘；菈菈先认不出人，后来只想起“爱哭鬼连”，让双方对童年关系的重视程度完全错位。
3. 连把梨斗视为竞争者，通过撕漫画、跑步等小挑战证明男子气概，却始终得不到菈菈肯定。
4. 梨斗本可期待菈菈跟连回宇宙，却开始在意两人的关系，显示解除婚约的愿望已经不再像最初那样单纯。
5. 连向周围人搜集男子汉定义仍无结果，随后受电影刺激，把普通校园竞争升级为极端训练。
6. 梨斗试图让菈菈直接认可连，以阻止事情继续扩大；连反而拒绝提前过关，坚持完成自己的标准。
7. 连通过一连串夸张挑战和 120 公里长跑，终于等到菈菈准备认可。
8. 苍蝇引发喷嚏，连在关键时刻变成伦；菈菈无法用“男子气概”评价少女，童年约定仍未兑现。

## 角色、种族与彩蛋

- 连（Ren）：菈菈的外星青梅竹马，把童年条件式约定视为正式承诺；认真、好胜，对“男子汉”的理解容易被夸张范本带偏。
- 伦（Run）：连打喷嚏后出现的女性形态，也是开场与梨斗相遇的少女。当前阶段两种形态共享同一身体与经历，不能误写成姐妹或同时站在现场的两个人。
- 性别转换种族：Fandom 英文写作 `memorzean`。本集确认喷嚏会触发连变成伦；如何从伦变回连、是否也是喷嚏触发，需要看片或后续集数确认。
- 《男人》／`Rocky VII`：戏仿《洛奇》式男子汉电影，是连把普通竞争升级成极端训练的直接诱因。画面标题和中文译法待核对。
- 自指漫画：连撕碎的漫画据 Fandom 称以《To LOVE-Ru》自身为原型，需直接看封面或内页确认。
- 本集是 TV 动画首次正式引入连与伦，也是 Fandom 所列“菈菈没有介绍新发明”的首集；沛凯仍然登场。

## 后续改编边界（当前只记录，不执行）

- 原作梨斗的同班主角位、被连挑战、意外接吻以及开始在意菈菈与连关系的剧情功能，后续统一映射给 User；不能另造男性梨斗，也不能把这些经历塞给夕崎梨子。
- “梨斗开始在意”是原作人物反应。改编到 User 时，不能擅自写成 User 已爱上菈菈、嫉妒连、希望两人离开或选定春菜；只能保留外部事件，并给玩家留下态度空间。
- 连与 User 的意外接吻若保留，应明确为突发碰撞，不建立恋爱、同意或取向结论，也不能替 User 固定厌恶之外的内心独白。
- 连／伦的性别转换是该角色自身的核心设定，不得借此复活“夕崎梨子是男性梨斗性转”的脏映射，也不得把伦拆成独立双胞胎。
- 用户允许面向主角的福利桥段，但本集若存在淋浴、衣物或变身笑点，不能自动扩大为路人围观或公开暴露；具体镜头应等看片后逐项决定保留、遮挡或改写。
- 菈菈幼年说过的条件式约定属于她与连的既往事实，不等于当前已经同意结婚，也不应由系统替 User 结算竞争胜负。

## 后续看片时优先核对

- 开场少女、苍蝇、喷嚏与“她来了”的完整镜头；是谁在观察伦。
- 连转校自我介绍、班级女生反应、称菈菈为新娘，以及菈菈想不起他时的陨石式打击画面。
- 童年照片里连的服装、菈菈如何称呼他，以及危险发明回忆一共有几段。
- 菈菈当年“变得有男子气概就结婚”的原句和语气，判断她是认真约定、安慰爱哭鬼，还是随口打发。
- 撕漫画、体育课超圈等前期挑战的准确顺序，漫画封面是否真为作品自指彩蛋。
- 连与梨斗意外接吻的肇因、目击者和后续反应。
- 连分别询问了谁、各人如何定义男子汉、他怎样把建议混在一起。
- 电影的片名、内容、`Rocky VII` 画面文字，以及训练和淋浴镜头的实际次数。
- 西日本番长、大脚怪、Johnny、棒球选手、巨大机器人等挑战是否都有片中正式名称，还是 Fandom 的描述性称呼。
- 120 公里数字是否出现在画面或台词中，菈菈准备认可连时说到哪一句被喷嚏打断。
- 连／伦所属种族的日文名称、喷嚏转换规则，以及片尾到底由谁负责解释。
