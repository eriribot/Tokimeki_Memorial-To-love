# 第十二集社区英文字幕时间锚点

## 证据性质

- 对象：2008 年 TV 动画《To LOVE-Ru》第 12 集《戦慄！　体育祭》的社区英文 ASS 字幕。
- 来源页：[SubDL 的 To LOVE-Ru 英文字幕页](https://subdl.com/subtitle/sd20803/to-love-ru-toraburu/english)；本轮直接核读压缩包中的 `To Love Ru - 12.enUS.ass`。
- 用途：给体育祭项目顺序、猿山连续解说、沙姬与菈菈的竞争、借物卡延迟回收、水上骑马战和保健室收尾提供可复查的对话时间锚点。
- 限制：这是第三方上传的社区字幕，不是官方译文，也不是逐帧看片。ASS 的说话人栏为空；下表依据连续对话、称呼与场景语义区分猿山和受邀评论员，仍应由日语原声或正片复核最终说话人。无对白动作由字幕区间与社区剧情／截图复盘交叉定位，时间也可能因片源片头或帧率不同略有偏移。

## 体育祭笑点的最小完整链

`猿山以热血播音开场 → 沙姬把宣誓变成对菈菈的挑战 → 校长越界主持热身并被拒绝 → 连抽到传说之剑并离场 → 原作梨斗抽到越界借物卡、拒绝执行却被菈菈装置强推 → 全员失格而猿山仍宣布继续 → 菈菈赢下爱情障碍赛 → 接力因连缺棒陷入落后 → 连带真剑回归并造成地裂 → 猿山取消接力、又请 User 顶替伤员加入春菜队 → 沙姬强改成水上骑马战 → 切割器被沛凯修复后失控 → 春菜昏倒、User优先救人 → 沙姬被自己的武器反噬、菈菈取帽获胜 → 保健室互相道歉 → 沙姬的大玉再次打断`

后续摘要若只留下“沙姬和菈菈进行泳装骑马战”，会同时丢掉三组真正支撑喜剧的延迟回收：连的荒唐借物卡最终毁掉接力、猿山无论事故多大都坚持播报、沙姬为了击败菈菈不断加码并被自己的作弊装置反噬。现代改编可以把福利限制在 User 的直接私密视角，但不能因此删掉这些因果所有者和回收节奏。
