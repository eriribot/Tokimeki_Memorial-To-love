# 第十一集社区英文字幕时间锚点

## 证据性质

- 对象：2008 年 TV 动画《To LOVE-Ru》第 11 集《金色の闇》的社区英文 ASS 字幕。
- 来源页：[SubDL 的 To LOVE-Ru 英文字幕页](https://subdl.com/subtitle/sd20803/to-love-ru-toraburu/english)；本轮直接核读压缩包中的 `To Love Ru - 11.enUS.ass`。
- 用途：给小暗初登场、鲷鱼烧、错误委托资料、拉可斯波揭露、互相保护和结尾留在地球提供可复查的对话时间锚点。
- 限制：这是第三方上传的社区字幕，不是官方译文，也不是逐帧看片。下表均为中文意译；无对白动作由字幕区间与 Fandom 顺序交叉定位。时间可能因片源片头或帧率不同略有偏移。

## 初登场的最小完整链

`递鲷鱼烧 → 确认目标并追杀 → 不还手与“极恶之徒”资料冲突 → 菈菈作证 → 拉可斯波暴露委托和假情报 → 小暗质问委托人 → 菈菈保护小暗 → User 保护菈菈 → 菈菈击退敌人 → 第一次被说可爱／“小暗”昵称由来得到说明并被允许 → 留在地球继续任务，同时答应交朋友`

后续摘要如果只保留“宇宙杀手来到地球追杀主角”，会丢掉小暗初登场真正的人物转折：她不是被击败后突然洗白，而是在职业原则、亲眼观察和第一次获得善意之间留下了尚未解决的矛盾。
