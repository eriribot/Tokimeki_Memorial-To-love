## 人物条目

`templates/character-entry.template.yaml`
是从真实世界书提取的春菜人物条目模板（字段名与酒馆导出 JSON 一致，正文用块标量便于编辑），仅作人工查看与编辑源，不会进入运行时包，也不代替真实
Tavern 世界书。

人物条目正文可以包含一对 `<称呼绑定>...</称呼绑定>` 标签，包住「对他人的称呼方式」中 User 那一行。运行时代码在注入扫描副本前，会用玩家注册的姓/名和当前好感把标签内的内容整段替换成具体称呼（规则在各角色
`GalMainStory/characters/*.ts` 的 `buildUserAddressBinding`）；标签缺失或出现多次会在生成前报错。标签内的静态文本同时充当未注册场景的兜底，应与上方模板保持一致。

## 第二集时间线校对

- 动画对白确认首次触碰追溯到“前天 20:43”，解除条件是婚约成立三日内再次触碰并宣告解除；不是二十四小时内证明性格不合。
- `4/8`、`4/9` 不是官方动画明示的剧中日期。TBS 页面所列 `2008/04/10` 是第 2 话播出日，不是故事日期。
