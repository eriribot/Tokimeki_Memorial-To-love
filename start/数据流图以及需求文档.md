# start 玩家登记与每存档 Persona 合同

## 当前实现合同（2026-08-10）

`start` 负责标题页、梨子确定性开场和主角登记。登记草稿在最终确认前只存在于组件本地；确认后写入当前新游戏已经取得的独立 `saveUuid`，资料不可编辑。

| 项目 | 当前合同 |
| --- | --- |
| 主角身份 | User 是主角；性别固定为男性，界面只读展示 |
| 必填字段 | 姓、名、生日月日、血型、外貌、性格 |
| 文本规则 | NFKC；普通空白折叠；控制字符拒绝；外貌和性格各最多 160 个 Unicode 字符 |
| 性格边界 | 只表示非关键语气与反应倾向，不授权模型替玩家决定关键行动、对白、路线或状态 |
| 存档 | `GameSnapshot` schema v4 严格保存完整 `PlayerProfile`；v3 及更早明确拒绝，不迁移 |
| 酒馆 Persona | 不创建、不切换、不修改真实 Persona；生成时只用当前存档资料做请求级覆盖 |

## 权威数据流

```text
startNewSession()
  └─ beginNewTavernAutosaveIdentity() → 独立 saveUuid

PlayerRegistration（本地草稿）
  └─ completeNewSessionRegistration()
       ├─ createPlayerProfile() → 规范化与严格校验
       ├─ playerStore.completeRegistration() → 唯一 PlayerProfile
       ├─ gameStore.completeRegistration() → registration → game
       └─ gameSaveApi.save() → 登记完成后立即保存

PlayerProfile
  ├─ GameSnapshot.player.profile（schema v4）
  ├─ CharacterArchivePanel（性别、生日、血型、外貌、性格）
  ├─ window.render_game_to_text().playerProfile
  └─ GenerateStoryActRequest.playerProfile（请求发起前冻结）
       ├─ <tolove_player_profile> 版本化 JSON 资料块
       ├─ overrides.persona_description 或一次性 depth-0 system 注入
       ├─ <tolove_player_identity_guard>：宿主 {{user}} 只作为传输别名
       ├─ 本次 WORLDINFO_ENTRIES_LOADED 清空 personaLore
       └─ GalStoryGenerationContext 保存资料签名、注入版本和承载方式
```

生成服务不得在异步读取世界书、等待模型或重试期间重新读取 `playerStore`。历史楼层重新生成前必须用当前存档完整资料重新计算签名；与原楼层不一致时拒绝生成，防止 A/B 存档串档。

## Persona 覆盖规则

1. 当前预设启用了 `personaDescription` 占位项：完整资料块通过 `overrides.persona_description` 覆盖，depth-0 只注入短身份护栏。
2. 占位项未启用：Persona Description 覆盖为空，完整资料块与护栏合并为一次性、`should_scan: false` 的 depth-0 system 注入。
3. 本次剧情世界书扫描删除 `personaLore` 副本，保留 Chat Lore、Character Lore、Global Lore 和项目选择的剧情/人物条目。
4. 成功、异常和取消都在 `finally` 停止一次性扫描钩子；剧情生成使用单请求互斥锁。
5. 这些操作不修改用户真实 Persona、Persona Lore、预设、世界书绑定或酒馆全局用户名。

## 验收边界

- 本地自动测试验证：v4 字段、危险结构转义、A/B 签名隔离、Persona 承载分支、Persona Lore 过滤、钩子清理和生成互斥。
- Prompt Preview 显示有效资料块、签名、承载方式、身份护栏及屏蔽来源。
- 真实酒馆仍需人工用 Prompt Itemization/Prompt Inspector 检查 Persona 的 None、Prompt Manager、Author's Note、At Depth 四种位置，并确认生成前后真实 Persona 与世界书配置不变。
- v1 不含头像上传、身高体重结构化字段、资料编辑、旧存档迁移或真实 Persona 同步。
