# 艾尔登特合同组件

艾尔登特把一次 AI 实现压缩成四类信息：

| Component | Required content                                 |
| --------- | ------------------------------------------------ |
| Intent    | 用户可见结果、本轮授权范围、完成标准             |
| Data      | 权威状态、相关模块、足够作出审查决定的证据       |
| Edges     | 禁止碰的内容、禁止触发的链路、需要停下问人的条件 |
| Answer    | 改动、验证、未触碰、接通状态、风险、人工决定     |

## Authorization and acceptance

- 显式用户请求授权当前实现轮。
- 当前轮可完成实现、非破坏验证，以及修复由本轮改动直接导致的失败。
- 新功能、相邻清理、外部写入、破坏性操作或新副作用链需要额外授权。
- AI 自检不构成人工接受。
- 审查邀请发出后冻结；没有完成人工审查，不开启下一实现轮。

## Connection labels

只选证据能证明的最强标签：

- 不涉及接通
- 只是界面草图
- 只是本地状态演示
- 已接入真实状态读取
- 已接入真实状态写入
- 已可作为正式流程使用

混合流程还要分别报告生成链、宿主消息链、插件/数据库链和 UI 镜像链。

## Evidence bar

验证项必须标记为 `passed`、`failed` 或 `not run`。没有复现步骤或真实运行证据时，不宣称外部验证成功。影响真实副作用的关键证据缺失时停止；非关键未知可以披露后交付。
