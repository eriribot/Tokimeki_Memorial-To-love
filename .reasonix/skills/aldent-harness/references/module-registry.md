# 艾尔登特模块登记表

模块登记说明权威状态、不可破坏的边界，以及授权和验收要求。未登记模块可先读和分析；跨模块实现必须先明确范围。

## 登记字段

```text
模块名：
负责 / 不负责：
权威输入 / 输出：
不可破坏：
当前明确请求内可直接做：
需要事前明确授权：
完成后必须人工验收：
验证证据：
```

“需要事前明确授权”只约束尚未被当前用户请求或已完成审查表授权的动作。“完成后必须人工验收”不阻止当前已授权实现。

## islandmilfcode

负责手帐楼层、续写/回溯/重生成、变量状态、手机、记忆库和剧情路由。

权威状态：宿主消息楼层是剧情记录权威；`stat_data` 是结构化状态入口；记忆库表保存长期事实。

不可破坏：

- `index.ts` 只做装配、初始化、生命周期和渲染调度。
- 页面不直接操作底层变量；prompt 层不写 DOM/变量；render 不触发生成。
- 重生成成功清空 `draft`，失败保留。
- `lastSummarizedIndex` 只前进，除非超过实际消息总数。
- 自动测试不能覆盖同范围的真人失败；被日期、路线或前置状态挡住的用例不算语义通过。

当前明确请求内可直接做：局部实现、文档/测试修正、类型检查、构建和回归检查。

需要事前明确授权：当前请求外的 prompt 主结构、变量 schema、记忆库时机、路线规则或大范围拆分。

完成后必须人工验收：prompt、楼层生成/回溯、变量写回、记忆库提交和路线推进的行为变化。

验证证据：职责搜索、TypeScript、构建、最小楼层交互、成功/失败重生成和摘要污染回归；语义改动保留陌生自然改写的正例、否定最小对、最终状态差异和真人结果。

## webgame-ui

负责游戏化界面、选项展示/选择、结算反馈和 Galgame 正文渲染。

权威状态：UI 本地状态不是剧情权威；正文渲染器只消费正文协议；结算权威来自明确的 store、宿主、数据库或插件状态源。

不可破坏：

- UI 不自行宣布剧情完成。
- 选项展示、选择、结算和正文渲染可分开审查。
- 模型不改算已经结算的状态。
- 重生成绑定当前阶段保存的 prompt/context。
- 本地成功不冒充宿主、插件或数据库成功。
- Drawer、modal、floating 或 overlay 只是条件化 shell；一个项目或一张截图不能升级成默认方案。

当前明确请求内可直接做：被明确要求的本地 UI/状态改动、相关测试和非破坏验证。

需要事前明确授权：请求外的真实生成/写入链、自动连续执行、结算规则、正文协议或同层主交互变化。

完成后必须人工验收：真实链路、选项结算、正文协议/抽取/渲染和重生成行为。

验证证据：截图、控制台、选择到结算日志、正文隔离、当前 prompt/context，以及要求的宿主/数据库证据；UI 外壳另需实际 game-frame 的目标设备/方向/键盘矩阵、替代方案比较和最新人工结论。

## bridgeapi_shujuku

负责把 UI 操作接回真实宿主聊天楼层，使原生规划、世界书、数据库和助手生成链路发生。

权威状态：真实宿主 chat 是权威；hidden user/assistant 楼层承载原生链；iframe 状态只是镜像。

不可破坏：

- 需要原生链的操作必须经过真实宿主消息。
- 世界书和数据库不能由 UI 缓存冒充。
- 接通失败必须可见。

当前明确请求内可直接做：已明确授权的局部桥接实现和只读诊断。

需要事前明确授权：请求外的 hidden floor、`/trigger await=true`、数据库写入时机、正则深度或世界书入口变化。

完成后必须人工验收：所有会改变真实宿主消息、插件钩子、数据库或世界书扫描行为的改动。

验证证据：最小真实楼层往返、hidden floors、世界书命中、数据库更新、失败 UI，以及四条链路日志。
