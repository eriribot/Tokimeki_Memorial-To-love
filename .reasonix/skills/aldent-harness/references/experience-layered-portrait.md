# 经验：分层动态立绘先还原坐标再做动画

## Use when

固定底图叠加眼睛、嘴巴图集或 Alpha mask，出现接缝、比例错误、表情错位、移动端漂移，或需要判断是否为 Live2D。

## Invariants

- 原始逻辑画布和证据确认的资产描述是坐标权威。
- 图集方向、帧数和顺序来自证据，不能从尺寸或文件名猜。
- 图集按帧窗口展开；响应式只移动或缩放完整舞台。
- 没有模型、网格或绑定数据时不宣称 Live2D。
- 缺失表情回退到稳定合法帧或显示明确错误。

## Required evidence

测量尺寸、Alpha 和有效包围盒；逐帧检查接缝；验证 PC、平板、手机横屏；让截图、运行时几何、资源日志和控制台互相证明。

完整流程见 `gal-layered-portrait-animation.md`。
