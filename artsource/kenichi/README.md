# 猿山健一分层立绘素材

角色 018（猿山），服装 01、姿势 01（`018_01_01`）。官方素材库另存在姿势 02（`018_01_02`，body `#2120`），
本项目未导出，当前目录全部是 01 对 01 的同一套。

运行时加载官方 legacy 容器；`clean/` 只作问题追溯，不覆盖或替代官方原图。

## 窗口坐标（1024x1024 逻辑舞台）

- eyes：`x=394, y=211, w=230, h=131`（官方 CSV 像素对齐值）
- mouth：`x=394, y=339, w=230, h=67`（官方表定位 + 同家族像素配准）

eyes 与 mouth 保留约 3px 重叠；mouth 的 67px 帧高让官方 atlas 覆盖到 body 的原下颌线。
固定套用通用 57px 帧高会留下第二条下巴，只把 mouth 下移又会暴露眼窗底边。

## clean 图集（历史试验，不用于运行时）

这些文件是 Kimi 生成的整数化/羽化对照输出，保留仅用于追溯本次黑线问题；官方原始素材不改写。

- 运行时按原始 `256x512` / `256x256` atlas 由通用 CSS 做三帧重采样。

表情语义（本项目映射）：`a` neutral、`b` worried（闭眼）、`c` serious、`d` anger、`e` shy、`f` happy（闭眼）。
`b`/`f` 基础眼型闭合，运行时关闭自动眨眼。
